# Workflow

1. Analyse : localiser classes, assets, graphes et dépendances.
2. Conception : proposer changements et critères d'acceptation.
3. Implémentation : modifier le minimum nécessaire.
4. Revue indépendante : logique, types de pins, références, null-safety, performance.
5. QA : compiler et exécuter les tests pertinents.
6. Documentation : fichiers touchés, décisions, limites, tests.
7. Rapport : résumé, changements, résultats, risques et validations restantes.

Ne jamais prétendre qu'un Blueprint a été modifié dans Unreal si aucune opération n'a été confirmée par l'éditeur.
